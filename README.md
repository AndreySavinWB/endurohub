# EnduroHub — бренд доступной мотоэкипировки

EnduroHub — рабочая папка бренда доступной одежды и экипировки для эндуро.

## Принцип бренда

Создавать честную, практичную и недорогую экипировку для реальной езды. Не переносить в продукт дорогие элементы из мотокросса только потому, что так устроен рынок. Каждая деталь должна решать подтверждённую проблему райдера и оправдывать свою стоимость.

## Первый продукт

[Комплект «штаны + джерси»](<01_Комплект_штаны_и_джерси/Бизнес-модель.md>)

Цель — яркий тренировочный комплект для эндуро стоимостью до 6 000 ₽ для покупателя, с усилением только реальных зон износа и использованием отдельной защиты райдера.
